## 二、小程序备案（ICP 备案）

**入口**：微信公众平台 → 设置 → 基本设置 → 小程序备案 → 开始备案

**要点**：
- 官方明确：**所有小游戏都需要完成备案（ICP 备案）才能发布上线** —— 与单不单机无关
- 材料：主体证件（个人 = 身份证）、人脸核验、小游戏名称/简介/类目、联系方式
- 备案主体要与小游戏主体**一致**（个人开发者 = 个人备案）
- 备案通过后再提交版本审核
- ⚠️ 名称一旦占用不能改，**先想清楚再填**

> 选「联网」还是「单机」？—— 选**联网**（云端算分 + 好友榜需要联网）。
> 表单里若要文字说明：
> 「游戏核心玩法（画圆、算分、结算）为纯本地实现，断网可正常游玩；联网功能用于云端算分校验与好友排行榜展示，断网时该局不计入排行榜，游戏主流程不受影响。」

## 三、游戏类目与软著

**类目**：二级类目应选「休闲 / 益智」一类，与实际内容（画圆打分）一致。

**软著**：
- 个人主体的小游戏在部分通道下**不强制**，但在应用商店/某些分发通道会要求
- 若最终通道要求 → 现在就申请（软件著作权登记约 1 个月，比 ICP 备案还接近关键路径）
- ⚠️ **先确认最终通道要不要它，再决定要不要现在申请** —— 否则白花 1 个月

## 五、`cleanup` 云函数（定时触发器 + 超时）

**为什么要**：隐私保护指引里声明了「审计记录保留 30 天」，声明与实际必须一致 —— 不删就是骗用户。

**代码已部署**（`cloudfunctions/cleanup/`，4 文件 / 6.6 KB，带 `--remote-npm-install`）。

**云端还差两步**：

| 项 | 值 | 入口 |
|---|---|---|
| 定时触发器 | Cron `0 0 3 * * * *`（每天凌晨 3 点） | 云开发控制台 → 云函数 → `cleanup` → 触发器 → 创建 |
| 超时时间 | **20 秒**（默认 3 秒偏紧，分批删可能跑不完） | 云开发控制台 → 云函数 → `cleanup` → 配置 |

**命令行版**（两条都需要 `--env` 指定环境）：

```bash
tcb fn trigger create cleanup --trigger-name daily --cron "0 0 3 * * * *" -e cloud1-d6grvs82r581230b2
tcb config update fn cleanup --timeout 20 -e cloud1-d6grvs82r581230b2
```

**验证**：控制台 → `cleanup` → 云端测试 → 直接调用，期望

```json
{ "ok": true, "cutoff": 1777408000, "retentionDays": 30, "deleted": 0, "batches": 0, "truncated": false }
```

`deleted: 0` 是对的（现在库里最老的记录才 6 天）。

> ⚠️ **改保留期天数要同步改后台的「服务内容声明」**（`core.js` 的 `RETENTION_DAYS` + 后台声明），
> 代码里的常量改动会在日志里喊一声提醒。

## 六、后台排行榜配置

托管数据的 key 是 `circle`（≤8 字符、全英文），后台排行榜配置要对得上：

| 项 | 值 |
|---|---|
| key | `circle` |
| 分数字段 | `wxgame.score`（Int32，真实分 × 10） |
| 段位字段 | `level`（与 `wxgame` 同级） |
| 更新字段 | `wxgame.update_time`（Unix 秒） |
| 好友榜开关 | 「向朋友公开」（`scope.WxFriendInteraction`） |

## 八、提审前自查清单

| # | 项 | 怎么验 |
|---|---|---|
| 1 | 好友榜在真机上有数据 | 两个都玩过这个游戏的微信号**互加好友** + 对方写过托管数据 |
| 2 | 「向朋友公开」弹窗能出 | 第一次点「好友排行」→ 微信弹窗 → 同意 |
| 3 | 好友榜的文字清晰 | 看绿字（临时诊断）：画布应为 1206×2622 物理像素 |
| 4 | 云端算分生效 | 云函数日志有 `score` 调用；数据库 `scores` 有真实 OPENID 的记录 |
| 5 | 托管数据写的是最高分 | 控制台 → 存储 → 用户数据 → `wxgame.score` = 最高分×10 |
| 6 | 隐私声明与实际一致 | 勾了「微信朋友关系」「昵称头像」「小游戏互动信息」「设备信息」，**没勾**「游戏社区数据」 |
| 7 | 提交内容与游戏一致 | 场景/玩法/系统功能按 README「上架审核的「必填内容」该怎么填」那节填 |
| 8 | 商业化那栏不空 | 明确写「不含货币/商城/兑换码/VIP/道具/红包」 |
| 9 | 提审版没有诊断浮层 | `CFG.DEBUG_OVERLAY` 与 `DEBUG_OVERLAY` 都应是 `false` ✓ |
| 10 | 云环境已转付费 | 免费版到期前转，否则线上调用受限 |

## 九、常见坑（都踩过）

| 坑 | 现象 | 根因 |
|---|---|---|
| scope 名写错 | 提示「请在设置里开启向朋友公开」，但设置页里**没有这一项** | 官方只有 `scope.WxFriendInteraction`，写错 → 微信从未记录过申请 → 不列出来 |
| 隐私声明没同步 | 授权弹窗**根本不出** | 服务内容声明提交后要等微信同步（数分钟~数小时） |
| 共享画布密度错 | 榜面文字**发虚** | 共享画布的位图必须是主域画布的**物理**尺寸（1206×2622），否则铺满屏幕时是放大 |
| 画布尺寸被钳制 | 卡片只有 77% 宽 | 开放域里设尺寸会被钳成屏幕逻辑尺寸 → 要**主域**来设 |
| 行高写死 | 16:9 机型上**最后几行被切掉** | 榜面页高度 = 屏幕比例 → 行高要自适应 |
| 部署漏依赖 | 云调用全挂，界面看不出异常 | `cli cloud functions deploy` 不带 `--remote-npm-install` → `wx-server-sdk` 缺失 |
| 部署时机 | `当前函数处于Updating状态` | 等十几秒重试 |
| 榜单是空的 | 榜上只有自己 | 单向好友可能拉不到；对方没写过托管数据就不算「玩过这个游戏」 |
